## 一、 项目概述与架构设计

### 1.1 项目背景
“解忧杂货铺”是一套专为高校学生打造的智能化校园心理陪伴与匿名树洞社区平台。系统结合现代化前沿 Web 技术与人工智能大语言模型（DeepSeek V4 API）、神经网络语音合成（Edge-TTS）以及本地动态安全防护机制，为广大学子提供具备高情绪价值的双向语音倾诉陪伴、匿名情感倾吐、治愈系智能回信及多媒体解压推送。

### 1.2 技术栈架构
* **后端框架**：Python 3.11 + Flask 轻量级 Web 框架
* **数据库**：SQLite 3 嵌入式数据库（无需配置，开箱即用）
* **大模型服务**：DeepSeek Open API (`deepseek-v4-flash`)
* **语音合成引擎**：`edge-tts` 异步神经网络语音合成（微软 Neural 音色库）
* **前端设计**：HTML5 + JavaScript (ES6) + Bootstrap 5 + ECharts 可视化图表库
基本功能：
1.学生端：
(1)账户与视觉功能：
①个性化注册登录与隐私管理：用户可通过账号+密码或邮箱+密码+验证码等方式快速注册登录，并能管理个人资料（包括头像、昵称及个人信息修改）。系统提供严格的匿名机制，保护学生在倾诉时的个人隐私。
②现代化界面与多主题切换：系统提供温馨/美观/简洁/前端的视觉界面，支持多主题切换，满足学生在不同场景下的视觉体验。
(2)语音陪伴核心交互：
①双向语音交互：支持学生端语音输入，智能体通过语音合成（TTS）技术将大模型的文本回复转化为对应角色音色进行播报，实现自然的语音交流。
②语音/触发唤醒与激活：
系统需实现智能体的激活功能。学生可根据开发能力选择实现以下一种或多种模式：
触发式激活：提供基础的交互按钮，用户点击后即可启动语音对话。
语音唤醒激活（进阶）：集成前端语音检测机制，支持通过特定自定义唤醒词实现“免点击”的智能体激活。
③多性格角色对话管理：借助主流AI大模型API实现流畅智能的对话。系统提供多种预设性格的AI陪伴角色（如“温柔倾听者”、“理智树洞”等），通过区分消息样式和聊天框设计，让用户轻松把握对话节奏。
④对话历史分组与搜索：对话历史按日期分组展示，配备关键词搜索功能，方便用户查找过往的语音与文字交流内容。
(3)树洞广场模块：
①树洞发布草稿箱：支持学生在撰写长篇情绪倾诉或树洞文字时自动保存为草稿，或手动存入草稿箱，防止因意外退出导致内容丢失。
②树洞动态多维分类导航：树洞广场支持按不同话题板块（如情感交流、学业压力、人际关系、吐槽树洞）进行分类浏览，方便用户快速找到共鸣话题。
③树洞智能回信：在匿名树洞中，当学生发布负面情绪的树洞动态后，系统后台可调用AI智能体，针对学生发布的树洞动态，以“杂货铺店员”的身份在后台撰写一封宽慰学生的“树洞来信”，自动投递到该同学的收件箱。
④情绪触发式多媒体推送：当智能体在对话中识别到学生处于失眠、焦虑或期末周期末月备考高压等特定状态时，会自动在聊天框内推荐并推送精选的治愈系音乐、大自然白噪音视频链接（如B站、网易云音乐等校园高频平台链接）等，为学生提供即时的解压与陪伴服务。
⑤安全举报与内容过滤：在树洞广场中提供一键举报恶意言论的功能，且学生发布的内容会经过系统初步的敏感词本地过滤，确保社区环境的健康纯净。
 
学生端拓展功能：
①平台云端部署与上线发布：完成系统开发后，将整个管理平台实际部署至云服务器等平台上线发布，确保系统在真实网络环境下可公开正常访问与使用。
②定制化数字分身：允许学生在前台自主定义陪伴角色的名字、人设与说话风格，打造专属自己的解忧店员。
③声音克隆与音色自定义：支持学生上传一段简短的个人或特定语音样本，通过轻量级声音克隆技术，生成专属的对话音色，让陪伴声音更具亲切感。
④智能情绪分析与周报可视化：智能体能自动分析用户日常对话和树洞发言中的情感倾向，生成多维度的“情绪雷达图”与“解忧周报”，并以可视化图表直观展示情绪波动趋势
2.管理员端：
(1)运维与权限管理：
①多渠道管理员安全登录：支持管理员通过专属后台账号密码、绑定邮箱验证码等多种安全方式进行登录，系统自动根据预设凭证进行身份校验，保障后台系统安全。
②校园用户账号管理：提供对学生账户的统一管理面板，支持查看学生基本状态（如注册时间、账号状态），并具备账号禁用、启用及重置密码等基础运维功能，确保校园网络环境安全。
③对话与社区交互日志审计：系统自动记录管理员的操作日志（如删除树洞、封禁用户账号等行为），并提供基于时间、操作类型的日志搜索与导出功能，确保后台操作有据可查、合规透明。
(2)后台智能体配置：
①解忧杂货铺AI角色人设配置：管理员可直接在后台增加、修改或删除预设的AI陪伴角色。支持在界面上配置大模型API的底层提示词（Prompt）、设定角色的温和度、回复字数限制以及默认分配的语音合成（TTS）音色参数。
(3)树洞社区内容与安全治理：
①匿名树洞社区多维内容审核：提供树洞动态与评论的实时审核流水线。系统会自动标红触发本地敏感词的内容，管理员可进行一键下架、恢复或彻底删除操作，并能对恶意灌水或发表违规言论的用户进行封禁。
②校园通知公告与政策发布：内置富文本编辑器，管理员可自由编辑、排版并发布校园心理健康活动通知、讲座信息或紧急公告，支持设置公告的置顶状态、下线时间以及封面图片。
③系统敏感词词库动态维护：提供本地敏感词黑名单的管理功能，管理员可动态添加、批量导入或删除涉及违规、暴力的敏感词汇，该词库直接应用于学生端的树洞发布与评论过滤。
④学生举报事件仲裁中心：集中展示并处理由学生端提交的恶意言论举报。管理员可查看被举报的动态详情、举报原因及举报人说明，快速做出维持原状或下架处罚的仲裁判定。
 
管理员端拓展功能：
①可视化解忧数据看板：后台主页直观展示系统累计服务人次、当日活跃用户数、双向语音通话总时长、树洞高频热词词云图以及学生整体情绪倾向比例，方便数据汇报。
②树洞AI智能辅助初审：引入轻量级文本分类大模型，在管理员人工审核前，自动对树洞动态进行情感极值（如重度抑郁倾向、紧急求助倾向）及违规概率的智能打分与预警分类，帮助管理员优先处理紧急高危工单。
③系统公告千人千面智能推送：根据学生端积累的匿名心情标签或互动频率，系统后台可自动匹配最适合该群体的公告内容，实现校园心理健康资源的精准分发与智能触达。
